## Why it is separate

The drift experiment requires **150+ real post-cutoff atoms** with reliable
amendment-date metadata to produce meaningful comparisons between calibration
strategies (static, sliding-window, recency-weighted, triggered).

Without that data the experiment runs on synthetic risk scores that are
**not generated by a real regulatory drift process**, so the four strategies
produce **identical thresholds** — the `strategy` argument never reaches the
calibration function with data that distinguishes it.  Concretely:

- `sliding_window` and `static` return the same threshold because there are no
  real date labels to window on.
- `recency_weighted` falls back to a uniform ramp when dates are absent.
- `triggered` falls back to the static threshold because the violation rate
  never exceeds `delta` on synthetic data.

As a result, all four rows in the former `drift_table.json` had equal values,
which is misleading in a paper context.

## How to run (when real data is available)

```python
from experiments.drift.drift_exp import run_drift_experiment

result = run_drift_experiment(
    risks_pre=risks_pre,        # ≥ 150 pre-cutoff atoms
    labels_pre=labels_pre,
    risks_post=risks_post,      # ≥ 150 post-cutoff atoms
    labels_post=labels_post,
    dates_pre=dates_pre,        # ISO-8601 date strings per atom
    dates_post=dates_post,
    cutoff_date="2024-01-01",
    eps=0.05,
    delta=0.10,
)
print(result.best_strategy())
print(result.summary_table())
```

Results with `n_pre < 150` or `n_post < 150` are flagged
`status: "not_certifiable"` and must not be reported in the paper.
